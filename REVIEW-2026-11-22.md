# Revisão de 22/11/2026

Escopo: recomendações verificáveis das referências enviadas, preservando a identidade e os cadastros existentes.

## Alterações
- Player do YouTube carregado após clique; miniaturas externas continuam presentes.
- Catálogo compatível com navegadores sem AbortSignal.timeout; atualização do título e botão após chegada do catálogo.
- Rótulos e ajuda mais legíveis; foco visível roxo, respeito à redução de movimento e contraste forçado.
- Navegação recolhida até 1000px para evitar colisão dos links.
- Política pública impede objetos incorporados e alteração da base para outro domínio; referrer limitado entre origens. Não é uma CSP completa.
- Texto padrão de mensagens atualizado; conteúdo personalizado salvo pelo editor é preservado.

## Verificado no código
- Login limitado por usuário e IP, verificação de sessão e autorização administrativa no servidor.
- Chave administrativa lida de variável de ambiente no gateway, chamadas SQL parametrizadas por RPC.
- Uploads com limites de tamanho e tipos permitidos; biblioteca pública editável pelo Master, avatares em armazenamento privado.
- Gestão com política de conteúdo restritiva; links do Maps limitados a destinos permitidos.
- Varredura da cópia atual dos arquivos de código não encontrou padrões de chaves privadas, tokens GitHub ou chaves Stripe privadas. Não cobre todo o histórico remoto ou todos os provedores.

## Validação e limites
Teste de JavaScript confirmou catálogo, título como texto (sem interpretação HTML), ausência de iframe inicial e criação do player após clique. Prévia no navegador confirmou o fluxo.
Esta revisão não é teste de invasão ou certificação. Não foram alteradas políticas de acesso nem dados de membros. O histórico remoto, dependências transitivas dos serviços externos e restauração de backups não foram auditados integralmente.

## Adiado
Aviso de privacidade por solicitação do responsável. Não foram inventados termos, consentimentos, prazos ou contato jurídico. Monitoramento de sessões/PostHog não foi instalado: exige definição do projeto e tratamento dos dados antes de eventual ativação. Nenhuma promessa de evasão de detectores de IA foi aplicada.
